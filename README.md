# Papibeats God Mode - Android App

Rewritten from the original Papibeats repository into a high-performance native Android application using Kotlin and Jetpack Compose.

## Features
- **3D Spatial Touch Sphere / Pad ("God Mode")**: Interactive spatial audio touch pad mapping high frequency boosts (+15dB), bass boosts (+12dB), and center neutral (0dB) with real-time telemetry.
- **Special Audio Modes**: Active Noise Cancellation (ANC) shield with inverse phase injection and TalkThru voice amplification mode.
- **Room Acoustics Analyzer (SovereignEMA_G5618)**: Calculates axial room modes (Length, Width, Height) and resonance frequencies with integrated audio generation engine.
- **DSP & Equalizer**: Global audio band control and Sovereign DSP hardware sync status.
